holds manifests, Docker/compose, instruction files, ADRs, the product spec, and 10x-style

## Commands

See `context/map/delivery-and-verification.md`. Docker-first, dev stack: `docker compose -p
kivvi-dev up -d --build --wait` (never omit `-p` — prod runs under the bare project name
`kivvi-click` on this host, see Risks below). Production: `docker compose -p kivvi-click
--env-file .env.prod.docker -f compose.yaml -f compose.prod.yaml up -d --wait`, run from this
directory only.

## Invariants

- Postgres is the only backing service (sessions, event dedup, scheduler lock). No
  Redis/RabbitMQ/Kafka/Memcached.
- PL-first UI, EN optional; locale prefix routes (`/pl/...`, `/en/...`).
- Conventional Commits in English; trunk-based; no AI co-author trailers (global rule).
- Docker-first; do not assume a local JDK/Node outside the containers for anything but fast
  iteration.
- One deployable: the Spring Boot jar bundles the built SPA onto its own classpath.
